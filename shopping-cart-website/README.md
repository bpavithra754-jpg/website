# Shopping Cart Website

## Overview
This project is a simple shopping cart website built using HTML, CSS, and JavaScript. It allows users to view products, add them to a shopping cart, and manage their cart items.

## Project Structure
```
shopping-cart-website
├── src
│   ├── index.html        # Main HTML document
│   ├── styles
│   │   └── style.css     # CSS styles for the website
│   └── scripts
│       └── script.js     # JavaScript functionality for the shopping cart
├── assets
│   └── data.json         # Sample product data in JSON format
└── README.md             # Project documentation
```

## Getting Started

### Prerequisites
- A web browser (e.g., Chrome, Firefox)
- A code editor (e.g., VS Code)

### Installation
1. Clone the repository or download the project files.
2. Open the `shopping-cart-website` folder in your code editor.

### Running the Website
1. Open `src/index.html` in your web browser.
2. You should see the shopping cart interface with sample products.

### Features
- View a list of products with names, prices, and images.
- Add products to the shopping cart.
- Remove products from the shopping cart.
- Update the cart display dynamically.
